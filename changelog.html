2.3 开发日志｜两关试玩，持续开发中 2.3 Dev Log | Two-stage trial, in active development

目前开放「旧城区·放学路」与「云岚秘境」两个章节。接下来会优先处理操作、战斗平衡和稳定性，再扩展关卡。

Two chapters are open now: Old Town · After-School Road and Cloudmist Realm. Next priorities are controls, combat balance, and stability, then more stages.

本次更新

This update

  • 双女主切换：两关均可切换角色，分别使用丝袜丝带与拳术战斗。
  • Dual heroines: Switch characters in both stages — ribbon/stocking control vs close-range fists.
  • 商店与背包：增加独立按钮，支持储存药水、穿戴和卸下装备。
  • Shop & inventory: Dedicated buttons to store potions and equip / unequip gear.
  • 随机宝箱：两关加入金币与药水宝箱，开启状态随检查点存档保存。
  • Random chests: Coin and potion chests in both stages; open state saves with checkpoints.
  • 限时坐骑：香蕉猫不再跟随。每次手动召唤消耗 500 金币，持续 15 秒；到期离场，不会自动续召。
  • Timed mount: Banana Cat no longer follows automatically. Manual summon costs 500 coins for 15 seconds; it leaves when time is up and does not auto-renew.
  • 临时助战：第二关红衣师姐间歇出场，协助约 10 秒后离开。
  • Temporary ally: In stage 2, the red-clad senior sister appears intermittently and helps for about 10 seconds.
  • 移动问题修复：补充触控松开、手势取消时的输入清理，调整骑乘加速逻辑，处理人物持续往前冲的问题。
  • Movement fixes: Cleaner touch-release / gesture-cancel handling, mount acceleration tweaks, and a fix for characters sliding forward.
  • 中英文界面：同步更新新增功能的说明。
  • UI copy: Chinese and English labels updated for the new features.

当前验证情况

Current validation

两关模拟通关，以及部分触控、背包、宝箱、坐骑计时和存档逻辑测试已通过。

Simulated clears of both stages, plus spot checks for touch input, inventory, chests, mount timing, and save logic, have passed.

这些测试不代表所有设备都没有问题。真实手机、不同浏览器与长时间游玩的表现，仍需继续验证。

That does not mean every device is bug-free. Real phones, other browsers, and long sessions still need more testing.

试玩注意事项

Trial notes

  • 这是开发中的试玩版，并非最终版本，可能出现卡顿、按钮错位、碰撞或存档异常。
  • This is an in-development trial, not the final build. Expect stuttering, misaligned buttons, collision quirks, or save oddities.
  • 手机推荐横屏操作；进入游戏后点击开始以启用声音。
  • Landscape is recommended on phones. Tap Start after entering to enable audio.
  • 离开前使用游戏内的「存档返回」。继续游戏时回到最近检查点。
  • Use in-game “Save & Return” before leaving. Continue restores the nearest checkpoint.
  • 存档保存在当前浏览器，不是云存档。更换设备、浏览器、网站地址或清除网站数据，不会自动迁移进度。
  • Saves live in the current browser — not the cloud. Changing device, browser, site URL, or clearing site data will not migrate progress.
  • GitHub 仓库用于提供代码和下载文件；在线试玩需要另行部署，例如 GitHub Pages。
  • The GitHub repo hosts code and downloads; online play needs a separate deploy such as GitHub Pages.
  • 当前静态上传包不包含社区排行榜后端，仅上传到 GitHub 或部署静态页面，不会自动启用在线排行榜。
  • This static package has no community leaderboard backend. Uploading to GitHub or hosting a static page will not enable online rankings by itself.
  • 后续版本可能调整伤害、金币、装备与关卡内容，会尽量保留旧存档兼容性。
  • Later builds may tune damage, coins, gear, and stages; we will try to keep old saves compatible.

Bug 反馈

Bug reports

欢迎通过本仓库的 Issues 提交问题，请尽量提供：

Please file issues via this repo’s Issues. Include when you can:

  • 游戏版本、设备型号、浏览器名称。
  • Game version, device model, browser name.
  • 所在关卡、使用角色。
  • Stage and character in use.
  • 出问题前的操作，以及能否重复触发。
  • Steps before the bug, and whether it reproduces.
  • 截图或录屏。
  • Screenshot or screen recording.

游戏还在开发，欢迎试玩，也欢迎指出哪里不好玩、哪里不好操作。

The game is still in development — thanks for playing, and for pointing out what feels unfair or awkward to control.
